# 🤝 Contributing to Skipioo

Thanks for your interest in making Skipioo better! Every contribution matters — from a bug report to a star on this repo.

---

## Ways to Contribute

### 🐛 Report a Bug
Something broken? Open an [Issue](../../issues/new) with:
- What you were trying to do
- What happened instead
- Your browser and device (e.g. Chrome on Android)
- The YouTube URL you were trying to watch (if applicable)

### 💡 Suggest a Feature
Have an idea? Open an [Issue](../../issues/new) and tag it as a feature request. Explain:
- What you'd like to see
- Why it would be useful
- Any similar tools you've seen do it well

### 🌍 Help with Translations
Want to see Skipioo in your language? Open an Issue titled `[Translation] <Language Name>` and we'll coordinate from there.

### ⭐ Spread the Word
The simplest contribution: star this repo and share [skipioo.com](https://skipioo.com) with someone who'd benefit from it.

---

## Reporting Issues Checklist

Before opening an issue, please:
- [ ] Check if the issue already exists in [Issues](../../issues)
- [ ] Make sure you're using a supported browser (Chrome, Safari, Firefox, Edge)
- [ ] Try a different YouTube URL to see if it's specific to one video

---

## Code of Conduct

Be kind. Constructive feedback only. We're all here because we want a better, ad-free internet.

---

Thank you for being part of the Skipioo community! 🎬
