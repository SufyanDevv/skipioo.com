## What is Skipioo?

**Skipioo** is a free, privacy-first YouTube player that lets you watch any video, playlist, or live stream completely ad-free — no browser extension, no account, no subscription required.

Just paste a YouTube link. Hit play. Done.

## ⚡ 3 Ways to Use It

### 1. Paste any YouTube link
Go to [skipioo.com](https://skipioo.com), paste a URL, and watch instantly.

### 2. Replace the URL directly (Desktop)
Just swap `youtube` for `skipioo` in any YouTube URL:

```
youtube.com/watch?v=dQw4w9WgXcQ
        ↓
skipioo.com/watch?v=dQw4w9WgXcQ
```

Works for videos, playlists, and live streams:
```
youtube.com/playlist?list=PL...  →  skipioo.com/playlist?list=PL...
youtube.com/live/abc123          →  skipioo.com/live/abc123
```

### 3. Bookmark it
Bookmark [skipioo.com](https://skipioo.com) and use it every time you want to watch YouTube.
