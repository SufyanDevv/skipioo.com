# Skipioo

Watch YouTube videos in a clean, fast, distraction-free interface.

## Features

- Ad-free viewing
- Minimal UI
- Background playback
- Live stream support
- Privacy-focused
- No tracking

## Why Skipioo?

YouTube has become increasingly cluttered with:
- ads
- recommendations
- autoplay distractions
- tracking

Skipioo provides a cleaner alternative focused only on watching videos.
