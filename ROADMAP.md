# 🗺️ Skipioo Roadmap

This document outlines planned features, improvements, and ideas for Skipioo. Community feedback shapes these priorities — open an [Issue](../../issues) to vote or suggest something new.

---

## ✅ Shipped

- [x] Ad-free YouTube video playback
- [x] Playlist support
- [x] Live stream support
- [x] Background playback
- [x] Video downloads
- [x] Local watch history (browser-stored)
- [x] Direct URL substitution (`youtube.com` → `skipioo.com`)
- [x] Mobile & cross-browser support
- [x] Privacy-first: no tracking, no cookies

---

## 🚧 In Progress

- [ ] Improved mobile UI/UX
- [ ] Faster video load performance

---

## 🔜 Planned

- [ ] Dark/light theme toggle
- [ ] Keyboard shortcuts for playback control
- [ ] Shareable Skipioo links (auto-converted)
- [ ] Watch history export
- [ ] Multi-language interface support
- [ ] Browser bookmarklet for one-click conversion

---

## 💡 Ideas Under Consideration

These are community suggestions we're evaluating:

- [ ] Browser extension (for one-click redirect)
- [ ] PWA (installable as a mobile app)
- [ ] Queue / watch later list
- [ ] Picture-in-picture mode
- [ ] Subtitle/caption support

---

Have an idea? Open a [Feature Request](../../issues/new) and describe what you'd like to see. Popular requests get prioritized.
